🚀 What is computer?

Computer is a simple, powerful tool that gives your software agent its own virtual computer. Think of it as a sandbox where an AI, bot, or automation program can run tasks, browse the web, open files, and interact just like a human—but completely isolated from your main system. It's perfect for testing, monitoring, or running automated workflows without risking your personal data.

📥 Getting Started (Windows)

What you need

  • A Windows PC running Windows 10 or later.
  • At least 4GB of RAM (8GB recommended).
  • About 2GB of free disk space.
  • An internet connection for the initial download.

Step-by-step instructions

  1. Visit the download page – Click the large button above or the one in the section below to go to the releases page.
  2. Download the file – On the page, find the latest release. Look for a file named something like computer-setup.exe. Click it to download.
  3. Run the installer – Once downloaded, open your Downloads folder and double-click the file. If Windows SmartScreen shows a warning, click "Run anyway" (the software is safe).
  4. Follow the setup wizard – The installer will guide you. Choose your preferred installation folder (the default is fine) and click Install. This takes less than a minute.
  5. Launch computer – After installation, a shortcut will appear on your desktop. Double-click it to start the virtual computer for your agent.
  6. Give your agent access – Once the program opens, you'll see a simple dashboard. Click "Start Agent" to boot the virtual machine. Your agent can now use it!

That's it. No programming, no command line, no complicated settings.

❓ Frequently Asked Questions

Do I need to install anything else?

No. The installer includes everything you need. Just download and run it.

Will this affect my personal files?

No. The virtual computer runs in its own isolated environment. It cannot access your personal documents, photos, or applications unless you specifically allow it.

Can I use this on macOS or Linux?

Currently, computer is designed for Windows only. We may expand to other platforms in the future.

How do I update the software?

Just download the latest installer from the same link and run it. It will automatically replace the old version.

The agent doesn't start. What should I do?

Make sure your antivirus isn't blocking the program. Also check that you have at least 4GB of free RAM. If problems persist, restart your PC and try again.
