# Aquor Storefront Editor

Prototype: Hydrants & Valves collection page, product detail page, and an in-place editing toolbar (edit text/images/colors, manage nav, save view, share as PDF/JPG).

## Publish to GitHub Pages
1. Push this repo (this `index.html` at the root, or in `/docs`).
2. Repo Settings → Pages → set source to the branch/folder containing `index.html`.
3. Your tool will be live at `https://<username>.github.io/<repo>/`.

No build step — it's a single self-contained HTML file.
